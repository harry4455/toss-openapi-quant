# 백테스트 전략 로드맵

토스 OpenAPI 기반 백테스트에 적용할 전략 목록. 하나씩 개발 예정.

## ✅ 구현 완료

### 1. DCA (정액 분할매수)
- 정해진 주기(주별/월별)마다 고정 금액 매수.
- `src/backtest.py` `run_backtest()`, CLI `--freq/--weekday/--amount`.
- 하락장 방어 검증: 삼성 2024-07~2025-02 구간 -33.4%에서 DCA는 -11.80%.

### 2. 이평선 조건부 DCA (MA-filtered DCA)
- 종가가 N일 이동평균선 **아래(below)** 일 때만 매수, 아니면 배정금을 현금으로
  모아 다음 매수일에 투입("dry powder"). `above` 모드도 지원.
- CLI `--ma 20 --ma-mode below`.
- ⚠️ **해석 주의:** 조건 미충족 시 현금이 놀게 되어, 수익률(%)은 *투자된 금액 기준*이라
  유휴현금 기회비용(cash drag)을 과소평가함. 공정 비교하려면 "총 적립액 대비 수익"도 봐야 함.

### 3. 거치식 vs 적립식 비교 (Lump-sum vs DCA)
- 같은 총액(= 매수일 수 × 회당금액)을 ① 첫 매수일 일괄 vs ② 분할 비교.
- `backtest.compare_lumpsum_dca()`, CLI `--vs-lumpsum`.
- 검증 결과(삼성): 상승장 전체는 거치식 우세(+358% vs +349%, 단 MDD -43% vs -24%),
  하락장 구간은 DCA 압승(-11.8% vs -33.4%). → "기대수익은 거치식, 리스크 방어는 DCA" 확인.

### 4. 듀얼 모멘텀 (Dual Momentum)
- 매월 리밸런싱: 상대모멘텀(lookback 수익률 1위 자산) + 절대모멘텀(기준 이하면 회피).
- `src/momentum.py`, CLI `python -m src.momentum_cli --assets 069500:kr_etf,AAPL:us_stock --lookback 12`.
- **개선 적용:** ①안전자산 회피(`--safe-asset 153130`, 현금 대신 채권ETF로 — GEM 방식),
  ②매매 타임라인 출력, ③벤치마크(후보 동일비중 단순보유) 대비 초과수익 표시.
- 전액 로테이션 방식(거치식 계열). 통화 다르면 현재환율 단일값으로 KRW 환산.
- **미국 양도세(22%/연250만원공제) 반영 완료** — `us_capgains_tax()` 연단위 손익통산(net) +
  공제 후 22%, 최종 US 보유분은 청산 가정으로 실현. 세후 평가액·수익률·CAGR 출력.
  매도거래세·매수수수료는 전환 시 반영. 채권ETF는 kr_etf 분류(배당소득세 15.4%는 여전히 미반영).
  - **결과(10종목/8년/1억): 양도세 ₩8,900만, CAGR 94.24%→93.12%(약 −1.1%p)로 의외로 작음.**
    이유: 고수익 구간에 NVDA 2년 장기보유(미실현 무과세) + 연공제 + 종료 시 KR 보유.
    → 모멘텀의 발목은 세금이 아니라 파라미터 민감도·MDD. 단 회전율 높으면 세금 급증(도구가 반영).
- 검증(삼성/KODEX200/AAPL/VOO, 12개월): 모멘텀 +329% vs 벤치 +235.69%(초과 +93%p),
  **단 모멘텀 MDD -30% > 벤치 MDD -19%** → 수익은 높지만 단일자산 집중으로 변동성은 더 큼.
- **견고성 분석** (`src/validation.py`, CLI `--sweep 3,6,9,12` / `--walk-forward`):
  - Lookback 민감도: 3개월 +521% ~ 12개월 +329%, 편차 192%p → **파라미터 매우 민감(과최적화 주의)**.
    주의: 짧은 lookback일수록 워밍업이 적어 테스트 구간이 길어지는 교란 있음.
  - Walk-forward(6개월 창 19개): 플러스 79% / 벤치초과 79%로 일관성은 양호하나,
    **표준편차 60%p, 2024-09~12 4연속 손실(하락장 휩쏘)**. 후반 창들은 삼성 급등을 겹쳐 타
    (overlapping → 자기상관) 평균(+51%)이 중앙값(+26%)보다 부풀려짐.
  - 결론: "공짜 점심 아님". 상승추세엔 강하나 하락전환·횡보에 약하고 파라미터 의존 큼.

### 📊 긴 표본 교차검증 결과 (src/validation.py, 통합 CLI src/validate_cli.py)
12년(삼성)/8년(모멘텀) 데이터 + walk-forward(12개월 창/3개월 스텝)로 세 전략을 같은 틀로 검증.
**짧은 구간(2년)에서 좋아 보였던 모멘텀이 긴 표본에선 무너짐 → 검증 틀의 가치 입증.**

> 메서드 노트: 조건부(이평선/RSI) 숫자는 **룩어헤드 수정 후(다음날 시가 체결)** 기준으로 재검증(2026-06-28).
> 수정 전(당일 종가) 대비 소폭 변동했으나 방향성 결론은 그대로 유지됨.

| 전략 | 벤치 초과비율 | 중앙값수익 | 파라미터 민감도 | 판정 |
|---|---|---|---|---|
| DCA | 43% (vs 거치식) | +7.31% | - | 수익보다 리스크 분산용 |
| 이평선DCA(20일) | **73%** (vs 일반DCA) | +4.53% | **낮음(33%p)** | **견고한 소폭 우위 ✅** |
| 듀얼모멘텀(12개월) | **27%** (vs 동일비중) | +2.96% | **극심(785%p)** | 과최적화 함정 ⚠️ |

(이평선·RSI는 룩어헤드 수정 후 재검증 값. DCA·모멘텀은 비조건부/별도엔진이라 불변.)

- DCA: 거치식을 이긴 창 43%뿐 → 상승장 많은 장기엔 거치식이 유리(연구와 일치). DCA는 방어용.
- 이평선DCA: 일반 DCA를 73% 창에서 이기고 MA값 바꿔도 안정적 → 가장 실전적.
- 듀얼모멘텀: 동일비중 단순보유를 27% 창에서만 이김 + lookback 편차 785%p → 신뢰 어려움.
  (2년 구간 79% 초과는 최근 강세장 cherry-pick이었음.)

### 5. RSI 과매도 조건부 DCA
- RSI(N) < 임계치(기본 30)일 때만 매수, 아니면 현금 적립. `--rsi 14 --rsi-threshold 30`.
- ma_window·rsi_window 함께 주면 둘 다 충족해야 매수(AND). `_rsi()`는 단순평균 방식.
- 긴표본 검증(삼성 12년, 룩어헤드 수정 후): **일반 DCA 초과 80%(이평선 73%보다↑)**, 중앙값+11.25%,
  MDD-14.55%, 임계치 민감도 낮음(27%p) → **이평선 DCA와 함께 가장 견고한 축.**

### 모멘텀 재검증 — 종목군(universe) 영향 (중요)
- 4종목 → **10종목**(삼성/SK하이닉스/NAVER/현대차/KODEX200 + 애플/MS/엔비디아/VOO/QQQ)로 확장 재검증.
- 결과 급변: 동일비중 초과 **27% → 78%**, 중앙값 +2.96% → +47.65%.
  → **모멘텀은 후보군이 넓어 '갈아탈 승자'가 많을수록 유리**(narrow universe가 4종목 부진의 원인).
- ⚠️ 단, lookback 편차 **1502%p**로 여전히 극심, 평균 MDD -34%, std 145%p. 그리고 NVDA를
  사후적으로 알고 골랐다는 **선택편향(universe 자체가 숨은 파라미터)** + AI붐 구간 편중.
  → "universe만 넓히면 해결"이 아니라 여전히 고위험·고민감 전략.

## 📋 개발 예정 (우선순위 순)

### 6. Value Averaging (VA, 가치 평균법) — 우선순위 낮음
- "목표 평가액 곡선"을 정해두고, 실제 평가액이 미달이면 더 사고 초과면 덜 사거나 매도.
- ⚠️ **자료조사 결론: 우선순위 낮음.** 연구상 DCA가 61% 확률로 우세(평균 +3.2%p),
  현금 예비금 필요 + 최악엔 손실 100%+부채 위험. "더 똑똑한 DCA" 마케팅과 달리 실증 약함.
- 구현하더라도 비교군(벤치마크)으로만.
